# Build a YAML-driven static site generator

Build a CLI tool that reads YAML page descriptions and renders them into HTML using nested templates. Each YAML node names a template from `./templates/` and supplies parameters; nested `elements:` arrays compose templates recursively (header → nav, body → hero + content, footer → links, etc.). Given a directory, walk it for `*.yaml` files and emit matching `*.html` files preserving the directory structure. With `--watch`, monitor the input directory and rebuild a page whenever its YAML changes. Templates are bundled into the compiled binary so the tool ships as a single self-contained executable. Use the existing ARO website (`../../ARO-App/Website/src/`) as the reference output: templates and YAML files reproduce each page byte-for-byte.
